# Hawaii

361 cameras from GoAkamai (goakamai.org, HDOT on the ICx ATIS platform), live video,
built by `builders/build-states-hi.py`. Hawaii was blocked for days on one missing
thing, coordinates, and the door was in the site's own config file.

## Where the list comes from

The obvious API, `a.cameraservice.goakamai.org/cameratours/<tour>/cameras`, lists every
camera with snapshot and HLS but no location, and bare `/cameras` answers 403. The site's
`goakamai.org/data/config.json` names `MapDataServiceURLs.cctv` as `/cameras?format=mapPage`,
and that endpoint answers, with latitude and longitude on every camera, when the request
carries the two `x-icx-*` headers the site's Vue app always sends. `x-icx-copyright` is a
constant vendor string and `x-icx-ts` is the current time in milliseconds: a fetch recipe,
not a secret. Read 2026-07-12.

## How images and video are read

Snapshots are `betaimageserver.goakamai.org/SnapShot/320x240/<id>.jpg`. The feed writes
them as `http://` but the host serves the same JPEG over https, so they are upgraded in
place and Hawaii needs no proxy. The API's own `imageRefreshRate` is 120 seconds. Video is
cdn3.wowza.com HLS: no token, no DRM, CORS `*` on playlist and segments.

## What a camera gives us

Name, one view, snapshot poster plus stream.

## Known limits

- Stream rot is real: about half of sampled playlists 404 at any time, which is why the
  popup's is-it-moving check exists and why the builder samples several streams so the
  dead half cannot veto the living half.
- HDOT reports `status: OK` on all 52 cameras serving its "Image Temporarily Unavailable"
  card. The sweep's placeholder rule was calibrated on this state and greys them.

## Runbook

From the repo root:

```bash
python3 builders/build-states-hi.py
```

Expected: 361 cameras, `video: true`.
