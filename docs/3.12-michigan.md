# Michigan

783 cameras from MDOT's Mi Drive map, snapshot-only, built by
`builders/build-states-mi.py`. 79 of them are road-weather cameras that also carry a
weather reading.

## Where the list comes from

Two calls on mdotjboss.state.mi.us. `/MiDrive/camera/AllForMap/` returns one row per
camera with coordinates, id, title, and a `weatherId`, but not the image URL, so the builder
folds in `/MiDrive/camera/getCameraInformation/<id>` for each, which adds `link` (the
snapshot) and `weatherText` (an HTML table of RWIS readings, present only on the weather
cameras). Read 2026-07-11.

## How images and video are read

Traffic cameras are stills on `micamerasimages.net/thumbs/<name>.flv.jpg`; weather cameras
on `mdotjboss.state.mi.us/docs/drive/camfiles/rwis/<id>.jpg`. Both hosts are https and
answer a ranged GET, so no proxy. Mi Drive publishes no HLS or RTSP the browser can reach.

## What a camera gives us

Name, one view, and for weather cameras the readings as a chip. `orientation` is a full
sentence ("Traffic closest to camera is traveling south."), not a compass token, so it is
shown as the caption rather than forced into the chip vocabulary.

## Known limits

- Mi Drive lists some cameras twice; the builder groups by coordinate so the pins stay
  clickable.

## Runbook

From the repo root:

```bash
python3 builders/build-states-mi.py
```

Expected: 783 cameras, `video: false`.
