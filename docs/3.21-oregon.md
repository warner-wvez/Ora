# Oregon

1,127 cameras from ODOT TripCheck, snapshot-only, built by `builders/build-states-or.py`.

## Where the list comes from

TripCheck publishes its full camera inventory as an ESRI-style JSON file,
`tripcheck.com/Scripts/map/data/cctvinventory.js`, with latitude, longitude, title, route,
and a filename per feature. Read 2026-07-09.

## How images and video are read

The snapshot is `tripcheck.com/RoadCams/cams/<filename>`. No video.

## What a camera gives us

Title, route, one view. A feature with no filename is a location-only pin.

## Known limits

- Washington's feed redistributes 65 of these cameras; the Washington builder excludes
  tripcheck.com images so they are not pinned twice.

## Runbook

From the repo root:

```bash
python3 builders/build-states-or.py
```

Expected: 1,127 cameras, `video: false`.
