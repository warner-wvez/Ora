# Washington

1,524 cameras from WSDOT's Traveler Information API, snapshot-only, built by
`builders/build-states-wa.py`. The richest feed Ora reads: the only state that says which
way each camera looks and, after measurement, how often each image really changes.

## Where the list comes from

The WSDOT Traveler Information API, with a free `AccessCode` read from `WSDOT_API_KEY`
(key at wsdot.wa.gov/traffic/api). The builder stops with a one-line message when it is
unset. Read 2026-07-09.

## How images and video are read

Refreshing JPEGs from images.wsdot.wa.gov. There is no HLS anywhere in the product, and
the images carry no CORS header, so nothing about them can be read from the browser at
runtime; the sweep judges them server-side.

## What a camera gives us

Two per-view properties no other state carries, both from WSDOT itself:

- `facing`: `CameraLocation.Direction`, a single letter (N, S, E, W, B, O). WSDOT's own
  road-alert feed spells the identical vocabulary out ("Northbound", "Both Directions"),
  which is where the expansion comes from. It is the direction of travel the camera
  covers, not a compass bearing.
- `refresh_sec`: how often the camera replaces its JPEG, measured by
  `scripts/measure-refresh-wa.py` into `states/WA-refresh.json` and folded in at build
  time. See [Refresh rate](4.1-refresh-rate.md). The popup polls at that rate instead of a
  flat 30 seconds.

188 cameras sit on 47 shared coordinates (a ferry terminal aims three at one holding
lane), so each coordinate collapses into one feature with a view per camera. Both
properties hang off the view, not the location.

## Known limits

- `IsActive: true` lies: 11 cameras serve an image unchanged for over a day, and four
  ferry cameras have served the same bytes since September 2003. Those get an amber "no
  new image since" instead of a rate.
- Three exclusions, all deliberate: tripcheck.com images (ODOT's cameras, already in the
  Oregon layer), `RoadName == 'Airports'` (aviation webcams), and a loose bounding box as
  a guard against a bad row.
- Never filter this state with `states-outline.json`. The outline puts the Whidbey,
  Vashon, and Anacortes ferry cameras and the whole Vancouver riverbank outside the state
  and silently deletes 67 real cameras. [Decision 0011](6-decisions/0011-outline-is-not-a-filter.md).

## Runbook

From the repo root, with the key exported:

```bash
WSDOT_API_KEY=your-key python3 scripts/measure-refresh-wa.py 9 90   # optional, 14 minutes
WSDOT_API_KEY=your-key python3 builders/build-states-wa.py
```

Expected: 1,524 cameras, `video: false`.
