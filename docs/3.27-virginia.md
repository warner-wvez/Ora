# Virginia

1,684 cameras from VDOT 511's public REST endpoint, snapshot-only, built by
`builders/build-states-va.py`.

## Where the list comes from

`https://511.vdot.virginia.gov/services/map/array/cameras`, GeoJSON-like features with
coordinates, an `active` flag, a snapshot `image_url`, and an HLS `ios_url`. The
human-readable name is in `description`; `name` holds the stream token. Read 2026-07-09.

## How images and video are read

The snapshot `image_url`. Video is not used: the stream host would not verify CORS and its
tokens may be short-lived.

## What a camera gives us

Description as the name, route and direction as the roadway, one view. Inactive and
image-less cameras are kept as pins.

## Known limits

- Snapshot-only until the stream host is checked again.

## Runbook

From the repo root:

```bash
python3 builders/build-states-va.py
```

Expected: 1,684 cameras, `video: false`.
