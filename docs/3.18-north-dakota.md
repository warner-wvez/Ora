# North Dakota

186 camera sites with 798 views from NDDOT's Travel Information Map, snapshot-only, built
by `builders/build-states-nd.py`.

## Where the list comes from

One static GeoJSON, `travelfiles.dot.nd.gov/geojson/cameras/cameras.json` (the app appends
a `?ts=` cache-buster; the bare path serves the current file). Each feature is a site with
a nested `Cameras` array, one entry per lens ("Ray - West", "Ray - Pavement"). Read
2026-07-11.

## How images and video are read

Images are `https://www.dot.nd.gov/travel-info/cameras/<name>.jpg`. No HLS anywhere.

## What a camera gives us

Site name, a view per lens. `Direction` on a lens is a view label ("West", "Pavement"),
not a travel heading, so it drives the tab and there is no compass chip. `Region` (the
NDDOT maintenance area) fills the county slot and the first highway description fills the
roadway.

## Known limits

- A handful of lens images redirect to a "not found" page when a lens is retired; the
  sweep greys those and the site stays a real pin.

## Runbook

From the repo root:

```bash
python3 builders/build-states-nd.py
```

Expected: 186 sites, `video: false`.
