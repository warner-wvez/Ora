# Kentucky

241 cameras from KYTC's public ArcGIS feed, snapshot-only, built by
`builders/build-states-ky.py`.

## Where the list comes from

Both of Kentucky's camera surfaces, maps.kytc.ky.gov/trafficcameras and the GoKY 511 map,
read the same open FeatureServer layer, `trafficCamerasCur_Prd` on services2.arcgis.com,
no key, `f=json`. 250 rows with description, snapshot URL, and coordinates. Read
2026-07-12.

## How images and video are read

Snapshots live on www.trimarc.org, KYTC's traffic-management site, and are fast:
`Last-Modified` lands within the last minute on every sampled image. 237 rows are https.
Of the 13 http rows, four Bowling Green intersections serve the same JPEG over https and
are upgraded in place, keeping the state off the image proxy. No video is published
anywhere; GoKY's only stream-like endpoint is a truck-parking API behind a token.

## What a camera gives us

Name and one view.

## Known limits

- Nine Indiana-side rows around Louisville (INDOT's TrafficWise host and three trimarc
  stills) are dead from every door, http and https, and Ora's Indiana layer already carries
  those cameras live. They are dropped: a permanently dead duplicate is a grey pin lying
  about a camera another layer shows working, not location-first.

## Runbook

From the repo root:

```bash
python3 builders/build-states-ky.py
```

Expected: 241 cameras, `video: false`.
