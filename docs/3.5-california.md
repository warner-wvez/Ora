# California

3,197 cameras from Caltrans, snapshot-only, built by `builders/build-states-ca.py`.

## Where the list comes from

Caltrans publishes every CCTV in one JavaScript file, `cwwp2.dot.ca.gov/vm/js/cctv09.js`,
which says in its own comments that developers looking for data should read it. Each entry
is a byte-0xFF-delimited string: page URL, longitude, latitude, description, status (1 is
active). The file is decoded as latin-1 so the delimiter survives.

## How images and video are read

The snapshot URL is derived from the page URL: `/vm/loc/<district>/<name>.htm` becomes
`/data/<district>/cctv/image/<name>/<name>.jpg`, CORS-open. No video is published.

## What a camera gives us

Name and one view. Status is carried but no longer filters: the 2026-07-10 location-first
change took the state from 2,047 active cameras to 3,197 by keeping the 1,150 inactive
ones as pins.

## Known limits

- Inactive cameras are location-only pins; the sweep greys the ones whose image is stale.

## Runbook

From the repo root:

```bash
python3 builders/build-states-ca.py
```

Expected: 3,197 cameras, `video: false`.
