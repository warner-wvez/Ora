# Tennessee

667 cameras from TDOT's SmartWay open-data feed, live video, built by
`builders/build-states-tn.py`.

## Where the list comes from

`https://www.tdot.tn.gov/opendata/api/public/RoadwayCameras`. The feed 401s without an
`ApiKey` header; the value in the builder is the public key the smartway.tn.gov client
ships to every browser, quoted rather than leaked, with an `Origin` header that satisfies
the same gate the browser preflight passes. Read 2026-07-10.

## How images and video are read

`httpsVideoUrl` is HLS on the same SkyVDN platform as Texas and sends
`Access-Control-Allow-Origin: *`. The poster the feed hands out
(`tnsnapshots.com/thumbs/<name>.flv.png`) 301s to `tnsnapshots.com/<name>.png`; both hops
are https and both the browser and the sweep follow the redirect, so the URL is stored
verbatim. The rtmp, rtsp, and clsp variants are ignored.

## What a camera gives us

Name, one view, poster plus stream.

## Known limits

- None measured beyond the usual few percent of dead streams.

## Runbook

From the repo root:

```bash
python3 builders/build-states-tn.py
```

Expected: 667 cameras, `video: true`.
