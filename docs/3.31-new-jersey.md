# New Jersey

The one state not on the map. Verdict 2026-07-12: every camera New Jersey publishes is
video that a static page cannot play, and there is no still anywhere. This page lists
every door tried so nobody re-litigates it; if a door here reopens, that is the place to
start. [Decision 0004](6-decisions/0004-new-jersey-skipped.md).

## Where the list comes from

511nj.org's API lists 666 cameras with coordinates, behind a Keycloak anonymous-login flow
(encrypted request bodies, JWTs of about six minutes). Scriptable, but pointless while the
streams stay locked. NJDOT's site and the Turnpike Authority's are JavaScript shells over
the same backends.

## How images and video are read

Not at all, and the reasons are independent:

1. `nj-511.wink.co` (379 cameras): playlists 403 without an `?otp=` one-time token from
   `getHlsToken`, valid 300 seconds. An expiring credential cannot live in a static file
   ([decision 0002](6-decisions/0002-no-expiring-tokens.md)).
2. `njtpk-wink.xcmdata.org` (102 Turnpike cameras): playlists require `Referer: 511nj.org`,
   a header a browser page cannot set, and even then answer
   `Access-Control-Allow-Origin: https://511nj.org` only. Two locks.
3. The remaining 185 entries point at a literal `Camera-Unavailable.png`.
4. No snapshot or thumbnail endpoint exists on either CDN (`poster`, `preview`,
   `thumbnail`, `snapshot.jpg` all 403), unlike Mississippi's Wowza.
5. 511NY's feed used to carry 66 labelled New Jersey cameras on shared roads; since
   2026-07-12 its rows are labelled only "New York" or blank, so that partial door is gone.

## What a camera gives us

Nothing shipped.

## Known limits

The whole state. The 511ny feed's 66 cameras were the only honest partial, and it closed.

## Runbook

There is no builder. If wink.co ever serves a thumbnail, or the Turnpike CDN drops its
Referer check, start from the 511nj.org API list and follow the rules in
[Sources](3-sources.md).
