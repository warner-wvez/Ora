# Maine Turnpike

17 camera sites from the Maine Turnpike Authority, appended to Maine's 511 cameras by
`builders/build-states-me-turnpike.py`. Maine's other 134 cameras come from the
[511 DataTables feed](3.1-511-datatables.md).

## Where the list comes from

The turnpike map page hardcodes everything in `maineturnpike.com/assets/js/map.js`: a
`locations` array (id, name, lat, lng) where ids of 500 and above are camera mileposts,
and an if-else chain assigning each id up to three JPEG views (north, south, east) under
`/cameras/`. The builder parses that JavaScript with two regular expressions. Read
2026-07-12.

## How images and video are read

The images are live snapshots: `Last-Modified` tracks within a minute of now, and the page
refreshes them with a random cache-buster. No video is published anywhere on the site.

## What a camera gives us

Milepost name, up to three views per site.

## Known limits

- The JavaScript is hand-edited upstream: some longitudes read `- 70.6` with a space after
  the minus and one row has a bare `-`, so the regex allows an optional space. A new
  malformed row would be skipped, and the count would drop by one.
- The turnpike cameras are not in newengland511.org's Maine feed, so this script must run
  after the 511 builder, which writes `states/ME.json` wholesale. It is idempotent: it
  drops any existing maineturnpike.com features before appending.

## Runbook

From the repo root, in this order:

```bash
python3 builders/build-states.py ME
python3 builders/build-states-me-turnpike.py
```

Expected: Maine at 151 cameras, `video: false`.
