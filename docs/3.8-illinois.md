# Illinois

1,328 cameras from IDOT's Illinois Gateway Traffic Cameras dataset, snapshot-only. Illinois
was Ora's first layer and still ships as the standalone `cameras.json` rather than a
`states/` file.

## Where the list comes from

IDOT's public dataset on the Illinois GIS open data portal
(gis-idot.opendata.arcgis.com, "Illinois Gateway Traffic Cameras"), open ArcGIS data with
no key. The committed file is a preprocessed copy: rows collapsed from one per direction
to one pin per physical location, with every direction's snapshot nested under it.

## How images and video are read

Snapshots are served from `cctv.travelmidwest.com`, the public feed IDOT and its partner
agencies use for traveler information. That host blocks image requests carrying a
referrer, which is why `index.html` sets `<meta name="referrer" content="no-referrer">`
for the whole page. No video is published. Source images update every one to ten minutes
depending on the agency, so the layer polls every 30 seconds and cannot be more live than
that.

## What a camera gives us

Name, a view per direction with the view name stored as `direction` (the page reads
`label`, then `facing`, then `direction`; dropping the third once degraded 965 Illinois
cameras to "View 1, View 2").

## Known limits

- There is no builder script for this layer in the repo; the file was produced once from
  the dataset export. Folding it into `states/IL.json` with a builder is a code change on
  the map's layer config and is not yet done.
- Chicago's ticket cameras are a separate layer nested under Illinois in the sidebar; see
  [Chicago tickets](2.2-chicago-tickets.md).

## Runbook

None. To refresh, export the dataset from the portal again and regenerate `cameras.json`
in the same shape.
