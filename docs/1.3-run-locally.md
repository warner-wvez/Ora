# Run locally

Everything runs from the repo root. The map needs nothing but a static file server; the
builders need Python 3.12 and, for two states, a free API key.

## 1. Serve the map

```bash
git clone https://github.com/warner-wvez/Ora.git
cd Ora
python3 -m http.server 8934
```

Open `http://localhost:8934/`. The MapTiler key in the page is allowed on `localhost`, so
tiles load.

## 2. Rebuild one state

Every builder writes `states/<CODE>.json` relative to the working directory, so run it
from the root. The shared 511 builders take state codes; the bespoke ones take none.

```bash
python3 builders/build-states.py NY          # one of the 16 DataTables states
python3 builders/build-states-graphql.py     # all 7 GraphQL states
python3 builders/build-states-tx.py          # a bespoke state
```

Then compare the new count and video flag in `states/index.json` against the committed
values before committing. A relaxed filter should only ever add cameras; a drop means the
agency's feed changed, and [Sources](3-sources.md) says how to read that.

## 3. Keys for Ohio and Washington

```bash
cp .env.example .env      # fill in OHGO_API_KEY and WSDOT_API_KEY
set -a; source .env; set +a
python3 builders/build-states-oh.py
python3 builders/build-states-wa.py
```

Both keys are free: Ohio at publicapi.ohgo.com, Washington at wsdot.wa.gov/traffic/api.

## 4. Run the health sweep

```bash
python3 scripts/probe-health.py           # every snapshot state, about 40 minutes
python3 scripts/probe-health.py HI WA     # just these
```

It writes `states/health/<CODE>.json`. The scheduled workflow does the same every six
hours and commits the result; a local run is for checking a new state before it ships.

## 5. Check the docs

```bash
uv run --with markdown --with pytest pytest scripts/test_build_docs.py -q
uv run --with markdown python scripts/build_docs.py --check
uv run python scripts/refresh_numbers.py
```

The first two are what CI runs. The third rewrites the numbers in the README and the
overview from the data files, so run it after any builder or sweep changes a count.
