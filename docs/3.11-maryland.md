# Maryland

553 cameras from CHART (chart.maryland.gov, MDOT SHA), live video and no snapshots, built
by `builders/build-states-md.py`.

## Where the list comes from

CHART's export service is open: `GET
https://chartexp1.sha.maryland.gov/CHARTExportClientService/getCameraMapDataJSON.do`
returns every camera with coordinates, description, and its streaming host (`cctvIp`, one
of strmr3, strmr5, strmr10 on sha.maryland.gov). No capture was needed. Read 2026-07-12.

## How images and video are read

The public video page builds its player source as
`https://<cctvIp>/rtplive/<id>/playlist.m3u8`: Wowza HLS, no token, no DRM,
`Access-Control-Allow-Origin: *` on playlist and segments. Video-only, like Texas and
West Virginia: neither CHART nor the Wowza hosts expose a still (the Wowza thumbnail API
is disabled, CHART's own player uses a generic offline poster). The popup plays over a
dark backdrop and the runtime check catches a dead stream.

## What a camera gives us

Description as the name, one stream.

## Known limits

- No health file; video-only states are judged in the browser.
- The bounding box includes the Potomac bridge approaches; it rejects bad coordinates, not
  neighbouring cameras.

## Runbook

From the repo root:

```bash
python3 builders/build-states-md.py
```

Expected: 553 cameras, `video: true`.
