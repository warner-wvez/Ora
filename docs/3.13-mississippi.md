# Mississippi

411 camera sites with 956 views from MDOTtraffic (mdottraffic.com, Mississippi DOT), live
video, built by `builders/build-states-ms.py`. This state cost an evening to a filter
that impersonated a rate limit, and the lesson is written into the builder.

## Where the list comes from

The map is an ASP.NET WebForms page. `POST default.aspx/LoadCameraData` with a JSON
content type returns every camera site as `{tooltip, lat, lon, framehtml}`, no auth. A
site is a pole with one or more views; the per-site bubble page
(`mapbubbles/camerasite.aspx?site=N`) lists each view as a `switchImage(thumbnail, camId,
label)` call, so one GET per site turns the pole into the Washington-style tabbed shape.
Read 2026-07-12.

## How images and video are read

Every view is a Wowza stream at
`https://<streaminghost>.mdottraffic.com/rtplive/<camid>.stream/playlist.m3u8`, the host
being whichever one the site's thumbnail names. No token, no DRM, CORS `*` on playlist,
chunklist, and segments. Snapshots are Wowza's own thumbnail endpoint on the same host
(`/thumbnail?application=rtplive&streamname=<id>.stream`), which the site polls every
5 seconds. The camera identity lives in the query string, which `snapKey` and the sweep
preserve.

## What a camera gives us

Site name, a view per lens with its label, poster plus stream.

## Known limits

- **The trap.** Streaming hosts are regional: streamingjxn1 to 6 for Jackson, then
  streaminglym, streamingshvn, streaminggpt and others for the rest of the state. A host
  pattern that only knew Jackson silently dropped 254 of 411 sites while looking exactly
  like a rate limit: about 157 successes, then failures at a suspiciously stable count.
  The pattern now accepts any `streaming*` subdomain and the build refuses to ship if more
  than 5 percent of sites parse empty. When a scrape "gets throttled" at a stable number,
  suspect a filter eating valid rows first.

## Runbook

From the repo root:

```bash
python3 builders/build-states-ms.py
```

Expected: 411 sites, `video: true`. Takes a few minutes: one request per site.
