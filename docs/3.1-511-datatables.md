# The 511 DataTables feed

Sixteen states run the older Castle Rock "511" platform and expose the same three
endpoints, so one builder reads them all: Florida, Georgia, Utah, Pennsylvania, North
Carolina, Nevada, Arizona, Wisconsin, Idaho, Maine, New Hampshire, Vermont, Connecticut,
Louisiana, Alaska, and New York. Between them about 21,000 cameras. Video plays in
Florida, Pennsylvania, North Carolina, Nevada, Wisconsin, Louisiana, and New York.

## Where the list comes from

`https://<host>/List/GetData/Cameras` with a DataTables query in the URL: paged JSON with
the camera name, a `latLng` in WKT, image ids, and video URLs. The hosts are in `STATES`
in the builder (`fl511.com`, `511ga.org`, `udottraffic.utah.gov`, `www.511pa.com`,
`drivenc.gov`, `nvroads.com`, `az511.com`, `511wi.gov`, `511.idaho.gov`,
`www.newengland511.org`, `ctroads.org`, `511la.org`, `511.alaska.gov`, `511ny.org`).

Two feeds carry more than one state. `newengland511.org` serves Maine, New Hampshire, and
Vermont from one list, and `511ny.org` used to serve Connecticut and New Jersey cameras on
shared roads. A bounding box cannot separate them (Connecticut sits inside any New York
box), so the builder believes each row's own `state` column (`only_state`) and uses the
box only to catch null-island rows and a longitude that lost its sign.

## How images and video are read

The snapshot is `https://<host>/map/Cctv/<imageId>`, a JPEG the agency refreshes. Video is
the `videoUrl` on each image entry, an HLS playlist on some states. The builder samples up
to eight streams per state and refuses any URL carrying `token=`; Kansas and Massachusetts
are on the GraphQL platform, but the same rule applies here.

## What a camera gives us

Name, one or more views, the snapshot URL, the stream URL where it plays, and the feed's
`direction` column where present (New York labels 1,291 of its cameras Northbound,
Southbound, or Both Directions), which becomes the compass chip.

## Known limits

- About 5 percent of any state's cameras are down at a given moment. Georgia's placeholder
  rate measured 25 percent, Alaska 27, Florida 13, New York 9, Arizona 10.
- Georgia's video is 401 auth-gated, so Georgia is snapshot-only.
- New York: roughly a fifth of its 354 video-less cameras serve NYSDOT's "No live camera
  feed at this time" card. Since 2026-07-12 the 511ny feed labels rows only "New York" or
  blank, so the old door to 66 New Jersey cameras is closed.
- Georgia and North Carolina answer a HEAD request with `Content-Length: 0`; the sweep
  uses a range GET for that reason.

## Runbook

From the repo root:

```bash
python3 builders/build-states.py            # every state in STATES
python3 builders/build-states.py NY CT      # just these
python3 builders/build-states-me-turnpike.py   # after ME: appends the Maine Turnpike sites
```

The builder merges into `states/index.json`; it never overwrites entries built by other
scripts (it once did, and deleted six states, which is why it merges now).
