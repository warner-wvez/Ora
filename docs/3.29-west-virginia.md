# West Virginia

127 cameras from WV511 (wv511.org, WVDOH), live video and no snapshots, built by
`builders/build-states-wv.py`.

## Where the list comes from

WV511's Google Maps front end pulls its markers from
`wv511.org/wsvc/gmap.asmx/buildCamerasJSONjs`, a web method that answers with a
JavaScript file: cluster styling followed by a JSON array literal of cameras. The builder
slices out the array. Each row: `origin`, `md5` (the camera id), `title` (road),
`description` (an HTML blob whose first cell is the location), coordinates. Read
2026-07-11.

## How images and video are read

The stream is `https://vtc1.roadsummary.com/rtplive/<CAMID>/playlist.m3u8`, a Wowza edge
with CORS `*` on playlist and segments and no token. There is no still: the description's
image points at a `cam_unavailable.jpg`, so West Virginia is video-only like Texas.

## What a camera gives us

Road and location, one stream.

## Known limits

- About 60 to 70 percent of streams are dead at any time, an upstream condition. The
  popup falls back to an honest NOT LIVE with no snapshot to show; there is none.
- No health file; video-only.

## Runbook

From the repo root:

```bash
python3 builders/build-states-wv.py
```

Expected: 127 cameras, `video: true`.
